# UI 3.0 改动点与待办

更新日期：2026-10-08。状态：首版实现已落地，完整交付验收进行中。方向：将 MockMaster 升级为接口开发工作台，沿用 React + Ant Design，实现统一视觉、三栏布局与连续编辑体验。

## 范围与导航

- 本轮覆盖插件的模块、接口、嗅探、统计、设置页面；宣传网站不在范围内。
- 设置提供 UI 3.0 / 经典 UI 2.0 切换，按需加载各自布局与样式，刷新后记住偏好；两套界面共用相同 API 和存储。
- 保留现有接口 CRUD、模块/接口开关、多响应、分组、批量操作、文件代理、转发、录制、导入导出、WebDAV 和快捷键能力。
- UI 3.0 首版复用现有 API 与配置结构；匹配诊断、业务场景、响应级配置等新后端能力按 [项目待办](roadmap.md) 单独推进。
- 全局导航采用紧凑顶部导航，接口页左侧区域用于模块/分组树，避免同时出现两条宽侧栏。
- 旧主题偏好有迁移方案；保留赛博朋克/大地可选主题，优先完成默认浅色和深色体系，旧主题逐步接入统一 token。

## 一、视觉体系（第一阶段）

- [ ] U3-01 **统一设计 token**：主色、背景、分割线、文字层级、状态色、圆角、间距、字号和控件高度集中管理。默认使用中性色与单一主色；方法标签和状态标签规则固定。验收：页面无随意硬编码的主题色，状态有文字/图标辅助识别。
- [x] U3-02 **统一 ThemeProvider**：从 `AppLayout.js` 提取主题配置，支持浅色/深色及旧偏好迁移。验收：刷新和路由切换保留主题；表单、下拉、Modal、Drawer、提示消息和编辑区均跟随主题。
- [ ] U3-03 **清理样式冲突**：合并重复 reset，收敛通用类名，清理内联配色及多层 `!important` 覆盖。验收：修改单页样式不污染其他页面；代码字体与普通文本字体分离。
- [ ] U3-04 **建立公共页面组件**：统一 PageHeader、Toolbar、EmptyState、错误重试、加载状态与危险操作确认。验收：每页只有一个主标题，同一工具栏只有一个强主操作，空状态可直接进入创建/导入流程。

主要文件：`ui/src/components/AppLayout.js`、`ui/src/components/PageContainer.js`、`ui/src/styles/global.css`、`app-layout.css`、`cyber-theme.css`、`earth-theme.css` 及各页面样式。

## 二、应用壳与布局（第一阶段）

- [x] U3-05 **持久应用壳**：将 AppLayout 移至路由外，集中维护主题、全局导航、版本入口与快捷键帮助。验收：切换页面不重置应用壳状态，原有 HashRouter 路径和直接链接仍有效。
- [x] U3-06 **顶部导航与单一页头**：品牌、五个导航入口、版本整合至紧凑顶部栏；页面标题、上下文和操作放在一个页头。验收：去除重复标题/面包屑，当前页面与当前模块清晰可辨。
- [x] U3-07 **减少布局嵌套**：去掉内容容器与页面容器重复 padding，列表和编辑区直接占用工作区。验收：无卡片套卡片，同等窗口下数据区明显扩大，页面无整体横向溢出。
- [x] U3-08 **响应式与布局记忆**：保存面板宽度、折叠状态、列表密度；提供恢复默认入口。验收：1024px 可收起模块树，768px 以下列表/详情两级切换，360px 操作可达，不发生遮挡。

主要文件：`ui/src/index.js`、`ui/src/components/AppLayout.js`、`ui/src/styles/app-layout.css` 与五个页面组件。

## 三、接口工作台（第二阶段，核心）

- [ ] U3-09 **模块/分组树**：替代接口页模块下拉框，提供全部分组、模块状态与接口数量。验收：树与接口列表一致，切换模块保留合理筛选状态，禁用模块明确说明不会生效。
- [ ] U3-10 **紧凑接口列表**：展示名称、HTTP 方法、路径、启用状态、生效响应；搜索与分组筛选合并在列表顶部。验收：长 URL/名称可查看完整内容，搜索不丢失编辑草稿，选中项与详情一致。
- [ ] U3-11 **三栏可调整布局**：模块树、接口列表、详情编辑可折叠/调整宽度。验收：有最小宽度保护、键盘可调整，窄容器切换为列表→详情并可返回。
- [ ] U3-12 **保留批量管理**：勾选后显示批量操作条；保留批量启停、分组启停、表格视图/列设置等现有入口。验收：操作范围明确，筛选变化不误操作不可见项，失败保留选择并可重试。
- [ ] U3-13 **统一接口编辑器**：合并 Modal/Drawer 的重复表单，详情区使用同一个编辑组件；新建、复制、编辑共享校验和保存逻辑。验收：各入口字段和校验一致，URL/方法/代理类型/文件路径/目标地址均可配置。
- [ ] U3-14 **规则 / 响应 / 调试分区**：规则区放 URL、方法和参数条件；响应区放数据；调试区复用测试与真实录制。验收：不同代理类型只显示有效字段，调试结果明确区分配置预览、真实请求和未来匹配诊断。
- [ ] U3-15 **响应管理**：支持新增、复制、删除、排序与默认响应选择，清晰区分“正在编辑”和“当前生效”。验收：选择编辑对象不隐式切换运行响应，生效切换失败时回滚 UI，删除默认响应有明确替代规则。
- [ ] U3-16 **JSON 编辑体验**：提供格式化、语法校验、错误位置、复制与预览，非 JSON 内容保留纯文本模式。验收：无效 JSON 不被自动覆盖，大响应不卡死，代码区深浅主题可读。
- [x] U3-17 **草稿与保存反馈**：统一保存区、dirty 状态、保存中状态；切换接口/模块/路由及关闭编辑器时处理未保存修改。验收：失败保留草稿、不重复提交；保存后列表/详情同步；快捷键保存只作用于当前编辑器。

主要文件：`ui/src/pages/InterfaceManagementV2.js`、`ui/src/components/interface-management/ResponseContentEditor.js`、`DataManagementDrawer.js`、`DataManagementModal.js`、`InterfaceTestModal.js`、`RealResponseRecorder.js` 与 `interface-management.css`。

## 接口编辑流程简化（2026-10-29，本地未发布）

### 响应设置面板累积反馈（2026-11-03，本地未发布）
