## v1.2.2-beta.22

### ✨ Feature
- **入参匹配开关**：系统设置新增「接口入参匹配」和「响应入参匹配」两个显示开关，关闭后对应 UI 区域隐藏，同时后端运行时跳过对应匹配逻辑，直接使用默认响应
- **开关持久化**：开关状态通过 `app/cgi-bin/settings.js` 持久化到 `settings.json`，前端初始化时从后端同步，保证多端一致
- **记住功能模块**：接口管理页打开时自动恢复上次选择的功能模块；从功能模块页点击「查看接口」跳转时同步写入 `localStorage`，两处入口均保持记忆
- **参数匹配列联动**：接口列表「参数匹配」列中，接口级（橙色）和响应级（蓝色）标签分别受对应开关控制，开关关闭时对应标签不显示

### 🔧 Technical
- **新增 `app/cgi-bin/settings.js`**：CGI 处理器，支持 `GET`（读取）和 `PUT`（保存）设置，数据存储于 `settings.json`
- **`ruleManager.js` 升级**：引入 `getSettings()` 读取 `settings.json`，接口级匹配（同 URL 多接口区分 + 指定响应）和响应级匹配均受开关控制
- **`server.js`**：注册 `lib/routes/settings.js` 路由（`/api/settings`）

## v1.2.2-beta.18

### ✨ Feature
- **响应级入参匹配**：每个响应内容支持独立配置入参匹配规则，同一接口内不同入参可自动匹配返回不同响应，无需创建多个接口定义
- **动态响应选择**：运行时按响应列表顺序依次检查入参规则，第一个匹配成功的响应被返回；无规则的响应作为默认兜底
- **列表展示优化**：接口列表「当前响应」列在选项中显示 `[默认]` / `[N条规则]` 标签；「参数匹配」列区分展示接口级（橙色）和响应级（蓝色）规则数，Tooltip 展示详情
- **入参规则 UI 优化**：响应编辑器中入参匹配规则区域去掉折叠，直接展示，操作更直接

### 🐛 Fix
- **问题修复**：响应级入参匹配规则保存后重新编辑不显示——后端 `processInterfaceData` 和前端 `fetchInterfaces` 处理响应数据时均丢弃了 `paramMatchers` 字段，已补全
- **问题修复**：数据管理抽屉模式不生效——`displayMode` 状态、`useEffect` 监听及 `DataManagementDrawer` 导入丢失，已恢复
- **问题修复**：接口表单抽屉模式不生效——`interfaceFormDisplayMode` 状态及相关渲染逻辑丢失，已恢复

### 🔧 Technical
- **数据结构扩展**：`Response` 对象新增 `paramMatchers` 字段，后端 `processInterfaceData` 和前端数据处理均保留该字段
- **匹配逻辑升级**：`ruleManager.handleDataTemplate` 新增响应级入参匹配逻辑，命中后响应头 `X-Whistle-Mock-Response` 准确反映实际返回的响应
