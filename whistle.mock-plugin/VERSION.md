# 🔄 版本更新记录
## v1.2.2-beta.7
### ✨ Feature
- **交互增强**：接口表单（添加/编辑接口）支持弹窗/抽屉模式切换
- **设置新增**：系统设置页面新增"接口表单交互"开关，支持弹窗/抽屉模式切换
- **实时生效**：切换交互模式后立即生效，无需刷新页面
- **用户体验**：弹窗模式更适合快速操作，抽屉模式提供更大的操作空间

### 🔧 Technical
- **条件渲染**：根据 interfaceFormDisplayMode 配置动态选择 Modal 或 Drawer
- **配置管理**：使用 localStorage 存储交互模式配置
- **事件监听**：通过 storage 事件实现跨页面配置同步
- **表单复用**：Modal 和 Drawer 共享相同的表单逻辑和验证规则
